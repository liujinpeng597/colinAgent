# colinAgent

Python 基础学习笔记与示例代码。每章一个可独立运行的文件，按知识点逐行注释讲解 Python 语法，并在每个知识点后附 **"[C++] 对照 ↓"** 段落，给出等价的 C++ 写法，便于从 C++ 背景迁移。

## 内容

| 文件 | 内容 |
| --- | --- |
| `01_variables_types_io.py` | 第 1 章：变量、数据类型与输入输出 |
| `02_operators_expressions.py` | 第 2 章：运算符与表达式 |
| `03_strings_text.py` | 第 3 章：字符串与文本处理基础 |

三个文件由原来的 `hello_world.py` 按章节拆分而来。

## 运行

需要 Python 3：

```bash
py 01_variables_types_io.py
```

## 说明

- 各文件中的交互式输入示例默认关闭（`DEMO_INPUT = False`）；改成 `True` 后运行会停下来等待键盘输入。
- 注释中的 C++ 代码只用于对照，不参与运行。
- 文件编码为 UTF-8，文件头带有 `# -*- coding: utf-8 -*-`。
